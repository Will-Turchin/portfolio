## Add an image

1. Open the folder for the project.
2. Add up to five images named `01`, `02`, `03`, `04`, and `05`.
3. Use `.webp`, `.jpg`, `.jpeg`, or `.png` as the file extension.
4. Refresh the portfolio. The matching placeholder is replaced automatically.

For example, `self-hosted-platform/02.jpg` appears as the second image in the Self-Hosted Platform gallery. WebP is checked first and is recommended for smaller downloads.

Do not put multiple files with the same number in one folder; if that happens, the first supported format in the order WebP, JPG, JPEG, PNG is shown.
